Projeto de catálogo online

Mais opções para abastecer sua loja.

Um catálogo digital da FVB Materiais pensado para lojas de construção: encontre produtos, consulte itens e encaminhe pedidos com praticidade.

Ver projeto no GitHub Como executar o catálogo

O que o projeto oferece

A aplicação completa reúne a experiência de consulta do catálogo e ferramentas para a equipe administrar produtos e pedidos.

01 / CATÁLOGO

Encontre produtos

Pesquise por nome, marca, categoria ou código e navegue pelo catálogo em diferentes dispositivos.

02 / PEDIDOS

Monte uma solicitação

Organize os itens desejados e envie uma solicitação para continuar a negociação com a equipe.

03 / ADMINISTRAÇÃO

Gerencie o catálogo

Uma área protegida permite à equipe administrar produtos e acompanhar os pedidos registrados.

Sobre esta demonstração

Esta página apresenta o projeto e pode ser publicada gratuitamente pelo GitHub Pages.

Importante: GitHub Pages hospeda somente páginas estáticas. O catálogo interativo, login, pedidos e painel administrativo precisam do servidor Node.js e do banco SQLite; essas funções não estão disponíveis nesta demonstração. Consulte o repositório para executar a aplicação completa.
